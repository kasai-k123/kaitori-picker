# 宅配買取えらび — 公式データ調査メモ

調査日：2026年10月21日（JST）

## 位置づけ

- 5社・6コースの**申込に使う基本条件**を公式サイト・FAQ・利用規約から整理したもの。
- Codexの実装入力は同梱 `kaitori-official-data-2026-10-21.json`。追加ブラウジング不要。
- 「確認済み」は参照元の記載に基づくもので、実際の個別商品が買い取られる保証ではない。
- **未確認事項は不明として実装する。** キャンペーンによる点数変更や査定額推定を加えない。

### 見落としやすい例外

1. **買取王子**：査定結果を見て承認する場合は全品返送無料。一部のみの返送不可。自動承認は返送不可。初回・再本人確認時の受取は銀行振込に限る。査定結果に対する無回答が7日以上続くと承諾扱いになる旨のFAQあり。
2. **リコマース**：自動承認では発送後キャンセル不可。Amazonギフトカードのみで現金振込不可。初回は本人確認書類記載の住所から利用。衣類は買取対象外だがバッグ等は扱う。
3. **ブックオフ**：高額ソフト1点の例外は入力された商品名・査定見込額で判定できない。ゲームソフト1点・CD/DVD1点は「確認が必要」。本5冊のみは通常条件未達。ダンボールは原則自前、公式販売は1箱200円。2026年5月のサイトリニューアルに伴い申込トップが `https://sell.bookoff.co.jp/`。
4. **ネットオフ**：本・ゲームコースとブランド・総合コースで**返送料が逆**。本30点→10点に変わる会員限定クーポンが掲載されているが、一時的な適用条件なのでMVP判定には使わない。ゲーム機本体単品の最低点数は本・ゲームコースの通常案内だけでは未確定。別の家電コースの1点・返送料無料を混同しない。
5. **Pollet**：2026-09-01以降、2回目以降で査定総額500円未満なら査定額全額が送料に充当され、残高への付与は0円。追加請求はされない。銀行口座出金は通常1回200円（ランクによる無料回数あり）。査定後返送は着払い（公式目安1箱1,500〜3,000円）。査定通知から7日超は承諾扱い。雑誌、全巻揃わない漫画などに制限。CD/DVDはそれぞれ20点までの案内。沖縄県と離島は集荷不可。

## 機械判定に関する決定

- 申込対象の品目分類は7カテゴリ。複数ジャンル混在の判定はMVPでは行わない。
- `categories[category].state`: yes＝カテゴリ対応、no＝コース対象外、unknown＝ジャンルとして判断不可。
- `minItems: number` はそのカテゴリの**恒常的な基本最低点数**。null は未確認。
- 点数未指定なら点数条件は使わず、数値指定がある場合、`minItems=null` は unknown にする。
- 点数が最低数未満でも、高額ソフト例外のあるブックオフは unknown。
- 受取方法は「指定なし」と「銀行へ直接振込が必須」の2択。ギフトカード等も許容なら指定なしと同じ。Polletの残高経由は直接振込でない。
- 返送料無料の希望は**査定額を確認して売却を断れる場合**の無料返送を意味する。自動承認は不可。
- 分類：少なくとも1つ no → 除外、noなしでunknownあり → 確認が必要、全てyes → 条件に合う。
- 判定結果が確認の要る場合でも、根拠となった条件の短い説明を表示する。
- ソフト類の例外やPolletの20点上限は一括カテゴリでは誤判定しやすいため、**一括CD・DVD・Blu-rayの21点以上はunknown**にする。どうしても判定を明確にしたければUIカテゴリ分割に変更する。

## 未確定・意図的に外した項目

- Polletの全ジャンル共通最低申込点数を公式情報から確認できなかった。1点からとは表示しない。
- ネットオフのゲーム機本体単品の基本申込点数はコース情報だけでは確定できない。
- Polletのフィギュア全般およびネットオフ総合コースのフィギュアは商品別確認が必要。
- CD・DVD・Blu-ray一括カテゴリだとPolletのCD/DVD20点上限を正確に表現できない。推奨はCD・DVDとBlu-rayを分割するか、上限超をunknown扱いにする。
- ブックオフのソフト1点例外は買取価格が分からないためunknown。
- ネットオフ公式サイトの別「家電買取」の案内ではゲーム機1点・返送料無料。今回は本・ゲームコース側と混同しない。
- 各社個別商品の状態・ブランド・年代・地域などはカテゴリレベルでは保証不可。
- 正式な申込完了画面（ログイン必須含む）に深い直リンクは置かず、公式の申込入口を使用。
